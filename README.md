# <p align="center> HTML </p>
HTML (HyperText Markup Language) হলো একটি মার্কআপ ল্যাঙ্গুয়েজ, যা যেকোনো ওয়েবসাইটের মূল কঙ্কাল বা স্ট্রাকচার (Structure) তৈরি করতে ব্যবহার করা হয়। এটি কোনো প্রোগ্রামিং ল্যাঙ্গুয়েজ নয়, বরং এটি ব্রাউজারকে নির্দেশ দেয় যে ওয়েবসাইটের কোন কন্টেন্টটি কীভাবে সাজানো থাকবে।

নিচে HTML-এর মূল থিওরি বা বেসিক ধারণাসমূহ অত্যন্ত সহজ ভাষায় আলোচনা করা হলো:

## ১. HTML কীভাবে কাজ করে?
আপনি যখন আপনার এডিটরে (যেমন Acode বা VS Code) কোনো HTML কোড লিখে ফাইলটি .html এক্সটেনশন দিয়ে সেভ করেন, তখন ব্রাউজার (যেমন Chrome, Firefox) সেই কোডটি উপর থেকে নিচে লাইন বাই লাইন পড়ে। ব্রাউজার কোডের ভেতরের ট্যাগগুলোকে স্ক্রিনে দেখায় না, বরং ট্যাগের ভেতরের মূল লেখা বা ছবিগুলোকে সুন্দরভাবে সাজিয়ে ইউজারের সামনে উপস্থাপন করে।

## ২. HTML-এর মূল উপাদানসমূহ (Core Components)
HTML শেখার জন্য ৩টি মূল থিওরিটিক্যাল কনসেপ্ট বুঝতে হবে: Tag, Attribute, এবং Element।

### ক) Tag (ট্যাগ)
HTML-এ ব্রাউজারকে কোনো নির্দেশ দেওয়ার জন্য যে বিশেষ চিহ্ন ব্যবহার করা হয়, তাকে ট্যাগ বলে। এগুলো সবসময় অ্যাঙ্গেল ব্র্যাকেট (< >) দিয়ে শুরু এবং শেষ হয়।

সাধারণত ট্যাগ জোড়ায় জোড়ায় আসে। প্রথমটিকে বলা হয় Opening Tag এবং শেষেরটিকে বলা হয় Closing Tag (যেটিতে একটি স্ল্যাশ / থাকে)।

উদাহরণ: **`<h1>`** (Opening) এবং **`</h1>`** (Closing)।

### খ) Attribute (অ্যাট্রিবিউট)
ট্যাগের কার্যক্ষমতা বৃদ্ধি করার জন্য বা ট্যাগ সম্পর্কে অতিরিক্ত তথ্য দেওয়ার জন্য যে বিশেষ কি-ওয়ার্ড ব্যবহার করা হয়, তাকে অ্যাট্রিবিউট বলে। এগুলো সবসময় Opening Tag-এর ভেতরে বসে এবং এর একটি নির্দিষ্ট নাম ও ভ্যালু থাকে।

উদাহরণ: **`<a href="https://google.com">`** এখানে href হলো অ্যাট্রিবিউটের নাম এবং ওয়েবসাইটের লিংকটি হলো তার ভ্যালু।

### গ) Element (এলিমেন্ট)
ওপেনিং ট্যাগ থেকে শুরু করে ভেতরের কন্টেন্ট এবং ক্লোজিং ট্যাগ পর্যন্ত সম্পূর্ণ অংশটিকে একসাথে HTML Element বলা হয়।

## ৩. HTML DOM (Document Object Model)
ব্রাউজার যখন কোনো HTML পেজ লোড করে, তখন সে পুরো পেজের ট্যাগগুলোকে একটি গাছের ডালপালার মতো স্ট্রাকচারে সাজিয়ে নেয়। একে বলা হয় DOM Tree।

এখানে **`<html>`** ট্যাগটি হলো মেইন রুট (Root)।

এর দুটি প্রধান ডাল বা চাইল্ড হলো **`<head>`** এবং <body>।

**`<body>`** ট্যাগের ভেতরে আবার হেডিং, প্যারাগ্রাফ বা অন্যান্য ট্যাগ চাইল্ড হিসেবে যুক্ত থাকে।

## ৪. Block vs Inline Elements (খুবই গুরুত্বপূর্ণ থিওরি)
HTML-এর সব এলিমেন্ট স্ক্রিনে জায়গা নেওয়ার ওপর ভিত্তি করে দুই ভাগে বিভক্ত:

Block-level Elements: এরা স্ক্রিনের পুরো বাম থেকে ডান পাশ পর্যন্ত সবটুকু জায়গা (১০০% উইডথ) দখল করে নেয়। এদের নিচে বা পাশে কিছু লিখলে তা স্বয়ংক্রিয়ভাবে নতুন লাইনে চলে যায়।

উদাহরণ: **`<h1>`** থেকে **`<h6>`**, **`<p>`**, **`<div>`**, **`<form>`**, **`<ul>`**, **`<li>`** ইত্যাদি।

Inline Elements: এরা স্ক্রিনের পুরো জায়গা নেয় না, শুধুমাত্র কন্টেন্টের যতটুকু জায়গা দরকার ঠিক ততটুকুই নেয়। বাকি পাশে অন্য কোনো ইনলাইন এলিমেন্ট থাকলে তাকে বসতে দেয়, নিচে নামিয়ে দেয় না।

উদাহরণ: **`<a>`**, **`<strong>`**, **`<em>`**, **`<span>`** ইত্যাদি।


## ৫. Semantic vs Non-Semantic HTML
Non-Semantic: যে ট্যাগগুলোর নাম দেখে ভেতরের কন্টেন্ট সম্পর্কে কোনো ধারণা পাওয়া যায় না। যেমন: <div> বা <span>। (এরা কেবল সাধারণ বক্স বা কন্টেইনার)।

Semantic: যে ট্যাগগুলোর নাম দেখেই ব্রাউজার, সার্চ ইঞ্জিন (SEO) এবং মানুষ সহজে বুঝতে পারে এর কাজ কী।

উদাহরণ: **`<header>`** (উপরের অংশ), **`<nav>`** (মেনুবার), **`<main>`** (মূল কন্টেন্ট), **`<footer>`** (নিচের অংশ)। আধুনিক ওয়েব ডেভেলপমেন্টে কোড এসইও ফ্রেন্ডলি করার জন্য সিমেন্টিক ট্যাগ ব্যবহার করা বাধ্যতামূলক।

সংক্ষেপে HTML থিওরির সারসংক্ষেপ:
* ১. HTML একটি মার্কআপ ল্যাঙ্গুয়েজ, যা দিয়ে সাইটের লেআউট বা কঙ্কাল বানানো হয়।
* ২. এর মূল চালিকাশক্তি হলো Tags।
* ৩. পুরো পেজটি ব্রাউজারে একটি DOM Tree আকারে সাজানো থাকে।
* ৪. সিএসএস (CSS) ছাড়া শুধু HTML দিয়ে তৈরি করা ওয়েবসাইট দেখতে সাদা-কালো এবং অগোছালো লাগে। HTML স্ট্রাকচার তৈরি করার পর সিএসএস দিয়ে সেটিকে রঙিন ও সুন্দর করতে হয়।
















# 🌐 HTML5 Complete Tag Guide (Basics to Advanced)

স্বাগতম! এই গাইডটিতে HTML-এর শুরু থেকে শেষ পর্যন্ত **১০০% সব প্রয়োজনীয় এবং অ্যাডভান্সড ট্যাগ** বিস্তারিত ব্যাখ্যা এবং উদাহরণসহ দেওয়া হলো। কোনো গুরুত্বপূর্ণ ট্যাগ এখানে বাদ দেওয়া হয়নি। এটি আপনার HTML শেখার এবং রিভিশন দেওয়ার জন্য একটি কমপ্লিট চিটশিট (Cheat Sheet) হিসেবে কাজ করবে।

---

## 🛠 ১. Basic & Structural Tags (গঠনমূলক ট্যাগ)
একটি ওয়েবসাইটের মূল কঙ্কাল বা স্ট্রাকচার তৈরি করতে এই ট্যাগগুলো বাধ্যতামূলক।

* **`<!DOCTYPE html>`** : এটি কোনো ট্যাগ নয়, এটি ব্রাউজারকে বলে যে ফাইলটি HTML5 ভার্সনে লেখা।
* **`<html>`** : ওয়েবসাইটের রুট বা প্রধান ট্যাগ। এর ভেতরেই সব কোড থাকে।
* **`<head>`** : এর ভেতরে ওয়েবসাইটের মেটা ডাটা, টাইটেল, এবং সিএসএস লিংক থাকে (যা সরাসরি পেজে দেখা যায় না)।
* **`<title>`** : ব্রাউজারের ট্যাবে ওয়েবসাইটের যে নাম দেখায়।
* **`<body>`** : ওয়েবসাইটের আসল অংশ। আমরা স্ক্রিনে যা দেখি সব এর ভেতরে থাকে।

```html
<!DOCTYPE html>
<html lang="bn">
<head>
    <meta charset="UTF-8">
    <title>আমার ওয়েবসাইটের নাম</title>
</head>
<body>
    <h1>হ্যালো ওয়ার্ল্ড!</h1>
</body>
</html>
```





## 🔍 ২. Metadata Tags (মেটা ডাটা ট্যাগ)

* **`<meta>`** : ওয়েবসাইটের ক্যারেক্টার সেট (charset="UTF-8") বা মোবাইল রেসপন্সিভ ভিউপোর্ট সেট করার জন্য। (Self-closing)

* **`<link>`** : এক্সটার্নাল সিএসএস (CSS) ফাইল যুক্ত করার জন্য। (Self-closing)

* **`<style>`** : HTML ফাইলের ভেতরেই ইন্টার্নাল সিএসএস লেখার জন্য।

* **`<script>`** : জাভাস্ক্রিপ্ট (JavaScript) কোড বা ফাইল যুক্ত করার জন্য।


```
<head>
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <link rel="stylesheet" href="style.css">
    <style> body { background-color: #f0f0f0; } </style>
    <script src="script.js" defer></script>
</head>

```





## 📝 ৩. Text & Headings Tags (লেখালেখির ট্যাগ)
পেজে যেকোনো টেক্সট বা অনুচ্ছেদ দেখানোর জন্য এগুলো ব্যবহৃত হয়।

* **`<h1>`** থেকে **`<h6>`** : ৬টি স্তরের হেডিং। <h1> সবচেয়ে বড় এবং <h6> সবচেয়ে ছোট।

* **`<p>`** : প্যারাগ্রাফ বা সাধারণ অনুচ্ছেদ লেখার জন্য।

* **`<br>`** : নতুন লাইনে যাওয়ার জন্য (Line Break)। (Self-closing)

* **`<hr>`** : একটি সোজা আনুভূমিক রেখা বা দাগ টানার জন্য। (Self-closing)


```

<h1>প্রধান শিরোনাম</h1>
<p>এটি একটি প্যারাগ্রাফ।<br>এই লাইনটি নিচে নেমে গেছে।</p>
<hr>
<h2>উপ-শিরোনাম</h2>

```




# #  🎨 ৪. Text Formatting Tags (লেখা সাজানোর ট্যাগ)
লেখাকে মোটা, বাঁকা, বা অন্য কোনো স্টাইল দেওয়ার জন্য:

* **`<b>`** : লেখাকে শুধু মোটা (Bold) করে।

* **`<strong>`** : গুরুত্বপূর্ণ লেখা এবং মোটা করে দেখায় (SEO ফ্রেন্ডলি)।

* **`<i>`** : লেখাকে বাঁকা (Italic) করে।

* **`<em>`** : লেখার ওপর জোর দিতে বাঁকা করে (Emphasized)।

* **`<u>`** : লেখার নিচে আন্ডারলাইন দেয়।

* **`<mark>`** : লেখাকে হাইলাইট করে (হলুদ ব্যাকগ্রাউন্ড)।

* **`<small>`** : লেখাকে সাধারণের চেয়ে ছোট করে।

* **`<del>`** : লেখার মাঝখান দিয়ে কাটা দাগ দেয় (Deleted Text)।
* 



```
<p>এটি <strong>গুরুত্বপূর্ণ</strong> এবং এটি <mark>হাইলাইটেড</mark> লেখা।</p>
<p>পানির সংকেত: H<sub>2</sub>O এবং অংকের সূত্র: (a+b)<sup>2</sup></p>
<p>দাম: <del>৫০০ টাকা</del> এখন <ins>৩০০ টাকা</ins>।</p>
<pre>
   কোড যেভাবে লিখবেন
   ঠিক সেভাবেই দেখাবে।
</pre>
```


# # 🔗 ৫. Links & Multimedia (লিংক এবং মিডিয়া ট্যাগ)
ওয়েবসাইটে ছবি, ভিডিও বা অন্য সাইটের লিংক যুক্ত করার জন্য:

* **`<a>`** : হাইপারলিংক তৈরি করার জন্য (href=লিংক, target="_blank"=নতুন ট্যাব)।

* **`<img>`** : ছবি দেখানোর জন্য (src=ছবির সোর্স, alt=নাম)। (Self-closing)

* **`<audio>`** : অডিও বা গান বাজানোর জন্য (controls অ্যাট্রিবিউটসহ)।

* **`<video>`** : ভিডিও ফাইল চালানোর জন্য (controls, width সহ)।

* **`<source>`** : অডিও বা ভিডিওর সোর্স বা লিংক দেওয়ার জন্য এর ভেতরে ব্যবহৃত হয়।

* **`<iframe>`** : অন্য কোনো ওয়েবসাইট বা ইউটিউব ভিডিও নিজের সাইটের ভেতর ফ্রেম আকারে দেখানোর জন্য।


```
<a href="[https://google.com](https://google.com)" target="_blank">গুগল ভিজিট করুন</a>
<img src="logo.png" alt="কোম্পানি লোগো" width="200">
<video width="320" controls>
    <source src="video.mp4" type="video/mp4">
</video>
```
